模式C · 车载嵌入式

把这台手机当作装在车上的检测设备

这条路线的主张是边缘侧自治：采集、判定、提醒全部在设备本地完成，不依赖网络。 本页把手机当成车载设备来演示这一点 —— 整个页面不发起任何网络请求，画面不离开这台手机。

哪些是真的，哪些是模拟

真实 摄像头本地采集，逐帧在页面里真算亮度、清晰度（拉普拉斯方差）、 帧间运动量、人像区域面积与质心。
真实 镜头遮挡检测 —— 用手挡住摄像头，清晰度相对自身基线塌陷，会真的触发告警。 这是最值得亲手试一下的一项。
真实 防误报确认状态机 —— 从 common/schema/confirmation.py 移植的滑窗投票 + 最短持续时长 + 冷却 + 升级，参数与车端完全一致。
真实 本地语音播报（speechSynthesis）、震动（navigator.vibrate）、 断网时事件进本地队列、恢复后补传。
模拟 疲劳 / 安全带 / 手机 需要神经网络模型，浏览器里没有加载模型， 改由下方按钮手动注入信号。这类事件会标 模拟。
模拟 车速 来自滑块，代替 OBD-II / CAN 总线。超速判定本身是真算的 —— 超速无法从图像判断，必须接车辆信号。
非真实网络 后台 是页面内的模拟端点。本页不发任何网络请求， 「已送达 / 待补传」演示的是队列语义，不是真实上行链路。
