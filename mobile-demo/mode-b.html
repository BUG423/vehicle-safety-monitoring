哪些是真的，哪些是模拟的

  • 真实：摄像头画面的亮度 / 纹理 / 帧间变化逐帧计算，摄像头遮挡告警由此真实产生。
  • 真实：防误报确认状态机（滑窗投票 + 最短持续时长 + 冷却 + 升级）、 分级播报文案、双通道分发逻辑，与仓库里 common/ 的 Python 实现一致。
  • 模拟：安全带 / 疲劳 / 手机的逐帧判定。真实实现依赖服务器端 GPU 模型 （YOLO11-pose + MediaPipe 478 点人脸），手机浏览器里跑不了。
  • 模拟：车队里其余车辆的状态、历史事件、评分与图表数据。
  • 服务器端已实测：真模型在真实人像素材上 3/3 检出、0 误报、平均告警延迟 2.98 秒； 合成基准素材上 4/4 检出、0 误报，6 次眨眼与 3 次短暂低头干扰项全部未触发告警。 详见仓库 mode-b-server/README.md。
  • 真实：遮挡镜头时，安全带 / 疲劳 / 手机 / 分心会真实转为「未完成检查」 （decision=undecidable），照常上报后台但不播报给驾驶员，也不计入违规统计与评分。
  • 能力边界：超速无法从图像判断，必须接 OBD / CAN / GPS 信号； 本页所有超速事件均为模拟。
